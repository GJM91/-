# V-World 도시계획 규제 추출 (QGIS)

QGIS Python 콘솔에서 실행하여, 구역계(대상지) 기준으로 V-World OPEN API
데이터를 내려받아 도시계획 검토용 레이어를 만드는 스크립트입니다.

## 파일
- `03_vworld_urban_planning.py` — 실무용 추출 스크립트

## 하는 일
1. **두 개의 분석 범위** 생성
   - ① 구역계 (대상지 그 자체)
   - ② 구역계 + 2km : 경계에서 바깥으로 2km 오프셋한 "더 큰 사각형" (전체 맥락)
2. **V-World OPEN API 로 항상 전체 데이터** 수집
   - 용도지역·용도지구·용도구역·도시계획시설 등 각종 규제사항
     (국토관리 지역개발 > 용도지역지구)
   - 연속지적도_전국 (국토관리 지역개발 > 토지 > 연속지적도_전국, `LP_PA_CBND_BUBUN`)
3. **토지임야정보 CSV 조인**
   - **공공데이터포털(data.go.kr)** 의 `국가중점데이터 > 부동산 개방데이터 >
     국토교통부_토지(임야)정보` 에서 **파일데이터(CSV)** 를 전체 다운로드
   - 그 CSV를 연속지적도의 **PNU(고유번호)** 로 조인 → 지목·면적·공시지가 등 속성 부착
   - 대용량(전국) CSV 대비: 파일을 한 줄씩 스트리밍하며 지적도에 실제로 있는
     PNU 행만 골라 읽으므로 메모리 부담이 적음

> ℹ️ 데이터 출처가 둘로 나뉩니다.
> - **지적도(연속지적도)** = V-World 2D 데이터 API (GeoJSON 벡터, PNU 포함)
> - **토지임야정보** = 공공데이터포털 CSV (V-World 아님). PNU로 둘을 조인.
4. 결과를 ① 구역계 / ② 구역계+2km 두 벌로 클립하여 레이어 그룹으로 정리

## 사용법
1. 구역계(대상지) 폴리곤 레이어를 선택(활성)
2. `플러그인 > Python 콘솔 > 편집기`에서 이 파일을 열고 ▶ 실행
3. "토지임야정보 CSV" 파일을 물어보면 선택 (조인 불필요 시 취소)
4. 실행이 끝나면 홈 폴더의 `vworld_도시계획_결과.txt` 에 조회 로그가 저장됨

## 조정 포인트 (스크립트 상단 상수)
- `OFFSET_M = 2000` — 오프셋 거리(미터). 기본 2km
- `CLIP_WIDE_TO_RECT` — 광역 레이어를 사각형으로 자를지(True) / 걸친 필지 통째로 둘지(False)
- `REG_THEMES` — 조회할 규제 주제도 목록. 필요한 데이터ID를 추가 가능
- `PAGE_SIZE`, `MAX_PAGES` — 전체 데이터 페이징(끝까지 수집)
- `TILE_M` — 연속지적도 타일 한 변 길이(미터). 지적도가 여전히 덜 나오면 값을
  더 작게(예: 500), 요청이 너무 많으면 크게(예: 1000) 조정
- `MAX_TILES` — 타일 요청 수 상한(안전장치)

## 연속지적도(지적도) 관련 참고
연속지적도는 필지가 매우 조밀해서 넓은 영역을 한 번에 요청하면 V-World 가
오류/빈응답을 반환합니다. 그래서 이 스크립트는 분석 사각형을 `TILE_M` 크기의
작은 타일로 나눠 각각 조회한 뒤 PNU 기준으로 중복을 제거하여 **전체 필지**를
수집합니다. 진행 상황은 콘솔과 결과 txt 로그에 타일 단위로 기록됩니다.

## 참고
- `LP_PA_CBND_BUBUN`(연속지적도) 는 PNU 필드를 포함하며, CSV의 `고유번호`/`PNU`
  컬럼과 자동 매칭됩니다. CSV 인코딩(CP949/EUC-KR/UTF-8)과 구분자는 자동 감지합니다.
